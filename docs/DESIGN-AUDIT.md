# Phase D (11 Oct 2026)

## Motion acceptance checklist (tick the wallet's motion pass against this)

Source: DESIGN.md v2 §5.3 and §6. Spring = `SPRING` `{ stiffness 420, damping 40, mass 1 }` (ζ ≈ 0.98, settles ≈ 200 ms, no overshoot). Fade = `FADE` 180 ms `cubic-bezier(.2,.8,.2,1)`. Draw = `DRAW` 240 ms same curve. Reduced motion is read with `useReducedMotion()` **from `@keyline/ui`** (hydration-safe) and CSS `prefers-reduced-motion`. A motion passes only if all five columns match. **Anything the wallet animates that is not in this table fails** (no page transitions outside StackView, no list stagger, no hover lifts, no skeleton shimmer, no error shake).
